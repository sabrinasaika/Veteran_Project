Tips for best results

Include in your query:

  • Disability types (e.g. TBI, PTSD, mobility impairment, vision loss)
  • Life circumstances (e.g. recently divorced, housing instability)
  • Functional limitations (e.g. cognitive fatigue, wheelchair user)
  • Employment goals (e.g. remote work, federal jobs, self-employment)
  • Any prior work history or skills

The agent will:

  1. Parse the veteran's profile
  2. Search policy documents, PubMed research, VA/web resources, RSA-911 aggregates, and O*NET
  3. Run safe aggregate SQL over RSA-911 when a dataset question is asked
  4. Recommend a VA VR&E track
  5. Suggest specific occupation pathways with citations
  6. Flag evidence gaps explicitly
