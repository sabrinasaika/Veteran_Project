Transition Readiness Toolkit: A Tool to Promote Data-Driven Pre-ETS
About this Session
This session introduces the Transition Readiness Toolkit (TRT), a comprehensive set of assessment tools designed to improve transition services for students with disabilities. Developed to address challenges identified in Pre-Employment Transition Services (Pre-ETS), the toolkit provides real-time data and visual insights to guide vocational rehabilitation professionals in supporting measurable postsecondary goals. Participants will learn how the TRT enhances curriculum development and helps providers better serve students by using data to track progress and make informed decisions.
Learning Objectives:
Understand how the Transition Readiness Toolkit (TRT) supports Pre-ETS services,
by providing data-driven insights that guide curriculum development and support student progress toward postsecondary goals.
Learn how to implement the TRT’s assessment tools
to track and measure meaningful changes in students, empowering agencies to improve service delivery and decision-making.
